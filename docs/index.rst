de-ebsd simulation examples
========================================

Run the full simulation chain, inspect its intermediate objects, and project
dynamical master patterns onto an EBSD detector. The plots are interactive
anyplotlib figures, also usable as native widgets in Jupyter.

The gallery executes the Python examples during the documentation build and
provides downloadable Python scripts and Jupyter notebooks. For the CIF example,
download :download:`Si.cif <../examples/simulation/Si.cif>` alongside the notebook.
